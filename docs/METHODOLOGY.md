# Interpreting the atlas

**Updated on: October 2026**

The Heat Vulnerability Index (HVI) brings together **exposure**, **sensitivity** and **adaptive capacity**. Higher HVI indicates greater relative vulnerability; higher adaptive capacity represents greater protection.

## Reading the maps

| HVI class | Score |
|---|---|
| Very Low | 0–0.2 |
| Low | >0.2–0.4 |
| Moderate | >0.4–0.6 |
| High | >0.6–0.8 |
| Very High | >0.8–1 |

Other indicator maps divide values into five bands within the selected scale. Equal values can make these groups uneven. HVI filters always use HVI classes, even when another indicator is displayed.

Grid and ward scores are relative to their own scale. The highest-decile option shows the top-ranked tenth of areas. The sidebar average is the simple mean of currently visible HVI scores.

Area profiles show the score, rank, domain values and source indicators. Missing-source substitutions and small clipped grid fragments are flagged to support interpretation.

## Nearby healthcare

**Road-network mode** finds the five nearest reachable facilities using mapped road paths and available one-way directions. Total distance includes short access links between the selected point, the road network and each facility. Solid lines show roads; dotted lines show these estimated access links.

**Straight-line mode** finds the five closest facility points by direct geographic distance. Its ranking can differ from the road-network ranking. Distance rings always show straight-line radii.

A map click uses the clicked location. The button in an area profile uses a point inside the selected area. Facility-type filters apply before ranking. Routes are estimates and do not include live traffic, closures, turn restrictions or current facility availability.

## Context

Source years differ from the atlas update date. HVI describes relative vulnerability, not a current forecast or a validated prediction of heat-related illness. See [data sources and years](DATA.md).
